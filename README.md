# Prefill Race — what "fast" actually means for local AI

A single-page, real-time simulation of the moment that defines local LLM speed:
**the first response on an agentic harness**, when the model must re-read a
~60,000-token working context (system prompt, tool definitions, file reads,
conversation history) before it can type a single word.

Tweet-ready companion to the [Local AI Speed Simulator 2.0](https://eugeneclaw.github.io/local-ai-speed-simulator/)
engine: every number on this page is frozen from that engine's calibrated model
(measured anchors + vendor specs + honest estimates), generated at build time.
The page itself computes nothing.

## The race

Four machines × four models people are actually arguing about right now:

- **NVIDIA DGX Spark ×1 / ×2 / ×4** (128 GB LPDDR5X each, 273 GB/s, CX7 RoCE cluster)
- **Mac Studio M5 Ultra 256 GB** (1.2 TB/s unified — ships 22 Sep 2026, modelled pre-release)

- Qwen3.8-Flash-Next (176B/6B active — Qwen4 architecture preview)
- DeepSeek-V4-Flash-Vision-Exp (305B/13B, vision)
- GLM-5.3-Flash (320B/18B)
- GLM-5.3 (744B/40B — the big one)

All lanes prefill a REAL 61,475-token agentic transcript (generated by
Qwen3.8-27B working an actual Grafana-incident task: system prompt, 12 tool
schemas, 15 tool-result file dumps, 10-turn history) at each machine's modelled
rate, then type the 655-token final report at each machine's modelled decode
speed. First to finish wins. Lanes where the model doesn't physically fit show
why — GLM-5.3 Q4 (467 GB) fits none of the 256 GB machines; even 4× Spark only
holds it at Q2.

## Honesty

- Cold numbers assume NO prefix cache (first turn after load).
- M5 Ultra lanes are estimates from Apple's published 1.2 TB/s bandwidth, not
  measurements — units ship 22 Sep 2026.
- Apple's "up to 3× with four clustered systems" is a manufacturer claim and is
  deliberately NOT used as our cluster scaling; the engine models lower gains
  from measured all-reduce behaviour.
- Full provenance (source URL + class per figure) ships in race-data.json.
